# QFT-Benchmark

This repository contains a Jupyter notebook that implements the Quantum Fourier Transform (QFT) algorithm and its corresponding circuit using the PennyLane library. It compares the performance of QFT in terms of time and memory usage between the PennyLane implementation and a manual implementation.

## Files

- `qft_benchmark.ipynb` — Main Jupyter notebook for this project.

## Requirements

To run the notebook, you will need:
- Python 3.x
- An IDE that supports Jupyter notebooks, such as:
  - VSCode with Jupyter extension
  - JupyterLab
  - Jupyter Notebook
  - Google Colab

Running the first cell in the notebook will install the following dependencies:
- pennylane
- pandas
- numpy
- matplotlib
- memory_profiler

## How to Run

1. Clone the repository: `git clone https://github.com/vewester/QFT-Benchmark.git`
2. Navigate into the project folder: `cd QFT-Benchmark`
3. Launch the notebook:
   - JupyterLab: `jupyter lab`
   - Jupyter Notebook: `jupyter notebook`
